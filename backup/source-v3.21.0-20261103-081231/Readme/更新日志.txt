随机抽取器 更新日志
========================================

3.21.0（内容更新 · 问题修复） 2026-11-03  [最新]
  1. 顶部气泡提示加了跟随主题的边界框（深色模式下是深灰描边，不会出现刺眼白边）。
  2. 光锥池抽取报告的称号判定按 75% UP 基准加权：同样「歪了一半」的数据，光锥池会比角色池判得更非；角色池仍以 50% 为基准。
  3. 「本次抽取详情」里的可展开项目改为常态实色底（跟随主题，深色模式下不再只有鼠标悬停才看得出）。

3.20.0（内容更新 · 问题修复） 2026-11-02
  1. 高级抽取规则不再自动填入默认值：切换跃迁类型会清空面板，需要点「填入默认值」或自己填写，不同类型之间也不再互相保留数据。
  2. 概率 / 保底输入框只接受数字与小数点，粘贴非法内容会被拒绝；保存时新增校验：5 星、4 星总概率必须大于 0，概率提升值必须大于 0，4 星保底必须小于 5 星保底。
  3. 抽取报告按跃迁类型智能显示：光锥池按 80 抽保底（进度条绿色 ≤44、黄色 ≤62），角色 / 群星按 90 抽（≤50、≤70）；光锥池的报告写作「5星光锥 / UP5星光锥」，群星跃迁不显示「歪」标记与 UP 统计。
  4. 报告里的蓝色关键词改为真实的最长连 UP 次数：连续 4 次 UP 会显示「4连UP」，不再固定写「3连UP」。

3.19.0（内容更新 · 问题修复） 2026-11-02
  1. 切换跃迁类型时不再沿用上一个类型的数值：每个类型各自保留本次填写的数值，离开页面后清空。
  2. 高级抽卡规则的文案调整：「3星物品概率」改为「3星光锥概率」，「4星物品分类 / 4星角色分类」统一为「4星角色/光锥分类」，三种跃迁类型都生效。
  3. 群星跃迁面板把「4星角色/光锥分类」和「4星基础概率」挪到右侧一列，排版更紧凑。
  4. 修复控件获得键盘焦点时仍会出现虚线框的问题（现在包括下拉框在内都不再出现）。
  5. 修复弹出顶部气泡时底层界面会轻微抖动的问题。
  6. 更新日志的版本标记按规则重新核对：本次以及历史上同时包含内容更新与问题修复的版本，统一标为「内容更新 · 问题修复」。
